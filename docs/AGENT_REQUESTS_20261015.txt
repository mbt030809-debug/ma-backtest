VPS (Virtuoso -> PrimeSim GUI) 에이전트 요청 순서 (2026-10-15)
=====================================================================

기준 문서 : docs/PLAN_20261015.md  (별도 메일 "[VPS] PLAN full text" 본문을 그대로 저장해서 사용)
작업 위치 : 사내 서버의 프로젝트 폴더 (로컬 git, 외부 저장소 사용 안 함)

[진행 원칙]
- 한 번에 1개 요청만 전달, 완료 보고 확인 후 다음 요청
- 서버 확인이 필요한 요청(R2, R8)은 직접 서버에서 실행 후 결과를 다음 요청에 첨부
- 매 요청 끝에 아래 "공통 꼬리말"을 붙여서 전달

[R0] 사전 준비  (나의 할 일, 에이전트 요청 전)
---------------------------------------------------------------------
  1. 사내 서버에 프로젝트 폴더 생성 (예: ~/vps) 후 git init
  2. 별도 메일 "[VPS] PLAN full text" 본문을 복사해 docs/PLAN_20261015.md 로 저장
     ("=== PLAN 시작 ===" 다음 줄부터 "=== PLAN 끝 ===" 앞 줄까지)
  3. git add / git commit (최초 커밋)
  4. 에이전트를 이 폴더에서 실행한 뒤 R1 요청 시작
---------------------------------------------------------------------

[공통 꼬리말] (매 요청 끝에 그대로 붙이기)
---------------------------------------------------------------------
- docs/PLAN_20261015.md 를 먼저 끝까지 읽고 §0 작업 규칙을 따를 것
- [VERIFY] 항목은 하드코딩 금지, config 값으로 둘 것
- pytest, ruff check 모두 통과시킨 뒤 티켓 단위로 로컬 git 커밋 (원격 push 없음)
- 완료 보고: (1) 변경 파일 목록 (2) 테스트 결과 요약 (3) 남은 [VERIFY]/이슈 (4) 내가 서버에서 해야 할 일
---------------------------------------------------------------------
