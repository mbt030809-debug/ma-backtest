## 0. 에이전트 작업 규칙

- 언어/버전: **Python 3.11**, 타입힌트 필수, `dataclasses` 사용
- 개발 환경에는 **Virtuoso·PrimeSim 없음**
  - 모든 Virtuoso 호출은 `Bridge` 인터페이스 뒤에 둠 → 테스트는 `FakeBridge` + fixture로
  - 실제 연동 테스트는 `@pytest.mark.virtuoso`, `@pytest.mark.primesim` 마크 → 기본 skip
- 코어 패키지(`vps/` 중 `gui/` 제외)는 Qt 없이 import 가능해야 함
- 의존성 최소화: `skillbridge`, `numpy`, `pyyaml`, `jinja2` / GUI: `qtpy`, `pyqtgraph` (+ `PyQt5` 또는 `PySide6`)
- 품질: `pytest` 전부 통과, `ruff check` 통과
- 커밋: 티켓 단위 (§9), 브랜치 `claude/virtuoso-schematic-primesim-7sipmk`
- 생성 산출물(실행 디렉터리, 리포트 등) 이름에 날짜 `YYYYMMDD` 포함

## 1. 목표 / 비목표

### 목표 (v1)
1. Virtuoso 스케매틱 테스트벤치(lib/cell/view) 불러오기
2. 계층 전체에서 **설계 변수 자동 추출** → 값 입력/편집
3. `si` 배치로 **hspiceD 넷리스트** 생성
4. PrimeSim 덱 생성 → `primesim_sub -spice` 실행 → 종료 감지
5. 스케매틱 **클릭으로 전압/전류 프로브 등록** → `.probe` 자동 반영
6. 결과 파형 표시
7. 설정을 프로젝트 YAML로 저장/복원

### 비목표 (v1 제외)
- ADE 상태 읽기 (사용 안 함)
- 코너/몬테카를로/파라미터 스윕 (v2)
- FSDB 직접 파싱 (WaveView 연동으로 대체)

### 통신 원칙
- skillbridge는 **Python → Virtuoso 단방향 호출**
- Virtuoso 이벤트(클릭)는 SKILL 전역 큐에 적재 → Python이 300 ms마다 `vpsPopQueue()` 호출
- 무거운 순회는 **SKILL 쪽 함수 1회 호출로 처리 후 순수 리스트 반환** (원격 객체 왕복 최소화)
- skillbridge 호출은 **메인 스레드에서만** (스레드 안전 보장 안 됨)

## 5. 데이터 모델 (`vps/models.py`)

```python
@dataclass(frozen=True)
class CellRef:            # lib/cell/view
    lib: str; cell: str; view: str = "schematic"

@dataclass
class ParamRec:           # 인스턴스 파라미터 1개
    name: str; value: str; cdf_type: str = ""; parse_as_cel: str = ""; parse_as_number: str = ""

@dataclass
class InstRec:
    name: str; lib: str; cell: str; params: list[ParamRec]

@dataclass
class HierNode:           # 계층 1개 셀뷰
    path: str             # "" = top, "/I0", "/I0/I3"
    ref: CellRef
    insts: list[InstRec]

@dataclass
class VarUse:
    path: str; inst: str; param: str; expr: str

@dataclass
class Variable:
    name: str
    value: str | None = None          # None = 미입력
    uses: list[VarUse] = field(default_factory=list)

@dataclass
class ModelLib:
    path: str; section: str | None = None   # .lib 'path' section / section 없으면 .include

@dataclass
class Analysis:
    kind: Literal["tran", "dc", "ac", "op"]
    args: dict[str, str]              # tran: step, stop, [start], [extra]
                                      # dc: src, start, stop, step
                                      # ac: type(dec|lin|oct), points, fstart, fstop

@dataclass
class Probe:
    kind: Literal["V", "I"]
    sch_path: str                     # 스케매틱 계층 경로 "/I0"
    net: str = ""                     # 전압: 넷 이름
    inst: str = ""                    # 전류: 인스턴스
    term: str = ""                    # 전류: 터미널
    expr: str = ""                    # 해석 결과 "v(xi0.net12)", "i1(xi0.m0)"
    alias: str = ""
    status: Literal["ok", "unresolved", "error"] = "unresolved"
    message: str = ""

@dataclass
class Project:
    testbench: CellRef
    variables: dict[str, Variable]
    models: list[ModelLib]
    includes: list[str]
    temp: float | None
    options: dict[str, str]           # .option key=value (값 "" 이면 key만)
    analyses: list[Analysis]
    probes: list[Probe]
    netlist: dict                     # view_list, stop_list, max_depth 등 (§6.4)

@dataclass
class RunInfo:
    run_dir: Path; started: datetime; finished: datetime | None
    status: Literal["queued", "running", "done", "failed", "killed", "timeout"]
    job_id: str | None; cmd: list[str]; log_path: Path; outputs: list[Path]
```

```python
class SkillBridge(Bridge):
    # skillbridge.Workspace.open(workspace_id) 사용

    # 연결 끊김 시 BridgeError 발생, reconnect() 제공

class FakeBridge(Bridge):
    # tests/fixtures/*.json 기반
    # vpsGetHierarchy → hier_*.json, vpsPopQueue → probe_queue.json 순차 반환
    # 호출 기록 self.calls 보관 (테스트 검증용)
```

- 노출 SKILL 함수 (모두 §7에 정의)
  - `vpsVersion()` → `"vps-1"`

  - `vpsListCells(lib, view)` → 해당 view 보유 cell 목록
  - `vpsGetHierarchy(lib, cell, view, viewList, stopList, maxDepth)` → `[[path, lib, cell, view, [[inst, lib, cell, [[p, v, cdfType, cel, num], ...]], ...]], ...]`

  - `vpsHilightProbe(lib, cell, path, net)` / `vpsClearHilight()`
  - `vpsOpenTestbench(lib, cell, view)` → 스케매틱 창 열기

### 6.3 hierarchy.py + expr.py — 계층·변수 추출

**계층**
- `load_hierarchy(bridge, tb: CellRef, cfg) -> list[HierNode]`
- 반복 인스턴스 `I0<0:3>`은 이름 그대로 보관, 표시용으로 `expand_iter_name()` 제공

**expr.py 토크나이저**
- 입력: 파라미터 값 문자열 → 출력: 변수 후보 이름 집합
- 규칙
  - 따옴표 문자열 내부 무시
  - 숫자 토큰: `\d+(\.\d*)?([eE][-+]?\d+)?[A-Za-z]*` 및 `\.\d+...` → 무시 (`1u`, `10meg`, `2.5n`, `1e-9`)
  - 식별자: `[A-Za-z_][A-Za-z0-9_]*`
  - 식별자 뒤 `(` → 함수
    - `cel_wrappers` (pPar/iPar/atPar/dotPar) → **괄호 내부 전체 무시**
    - `known_functions` → 함수명만 무시, 인자는 계속 분석
    - 그 외 함수 → 경고 리스트에 추가
  - 예약어 무시: `temp`, `time`, `pi`, `e` (설정 가능)
- 반환: `ExprResult(vars: set[str], unknown_funcs: set[str], is_plain_number: bool)`

**변수 추출** `extract_variables(nodes, cfg) -> dict[str, Variable]`
- 대상 파라미터 판단
  - `parse_as_cel == "yes"` 또는 `parse_as_number == "yes"` → 분석
  - CDF 정보 없음(`cdf_type == ""`) → `param_exclude`에 없으면 분석
  - `cdf_type == "string"`이고 위 둘 다 아님 → 제외 (모델명 등)
- 대소문자: HSPICE 비구분 → 소문자 기준 병합, 원래 표기 유지, 대소문자만 다른 중복은 경고
- 각 변수에 `VarUse` 누적
- 결과 정렬: 이름순

**테스트**
- `"wn*2"` → {wn} / `"1.5u"` → {} / `"pPar(\"w\")*nf"` → {nf} / `"max(vdd, 1.2)"` → {vdd} / `"10meg"` → {} / `"\"nch\""` → {}
- fixture 계층 → 기대 변수 목록 일치

### 6.4 netlister.py — si 배치 넷리스팅

- `netlist(project, run_dir, cfg) -> NetlistResult(path, raw_path, log_path)`
- 절차
  1. `run_dir/si/` 생성
  2. `si.env` 작성

     ```
     simLibName = "<lib>"
     simCellName = "<cell>"
     simViewName = "<view>"
     simSimulator = "hspiceD"
     simNotIncremental = 't
     simReNetlistAll = 't
     simViewList = '("hspiceD" "hspice" "schematic" "cmos_sch" "symbol")
     simStopList = '("hspiceD" "hspice")
     simNetlistHier = 't
     ```
  3. `cfg.netlist.si_cmd` 템플릿 치환 후 실행 (cwd = cds.lib 있는 작업 디렉터리, 출력 → `si/si.log`)
  4. `output_candidates` 순서로 결과 파일 탐색 → `raw_path`
  5. 정리본 `run_dir/netlist.sp` 생성: `comment_out` 지시문으로 시작하는 줄(대소문자 무시, `+` 연속줄 포함)을 `* [vps] ` 접두로 주석 처리
- 실패 처리: 종료코드≠0 또는 결과 파일 없음 → `NetlistError` + `si.log` 마지막 50줄, `*ERROR*` 줄 요약
- 테스트: `subprocess.run` 모킹, si.env 내용 스냅샷, 정리 규칙 테스트

### 6.5 netlistdb.py — 넷리스트 파싱·이름 매핑

**파서** `parse_hspice(path) -> NetlistDB`
- 전처리: `+` 연속줄 결합, `*` 주석줄 제거, `$` 이후 인라인 주석 제거, `.include`는 따라가지 않음(옵션)
- `.subckt NAME port... [param=val...]` ~ `.ends` → `Subckt(name, ports, elements, nets)`
- 서브서킷 밖 소자 → `top`
- 소자 줄: 첫 토큰 = 이름, 첫 글자 = 타입
  - `x`: 노드들 + 서브서킷명(첫 `=` 포함 토큰 직전 토큰) + 파라미터
  - `m`: d g s b model params / `q`, `d`, `r`, `c`, `l`, `v`, `i`, `e`… 기본 노드 수 테이블
- `** Cell name: ...` 같은 주석에서 cell↔subckt 매핑 보조 정보 수집 (있으면)
- `nets` = 포트 ∪ 모든 소자 노드 (소문자 정규화 보조 인덱스)

**NameMapper**
- `map_path(sch_path) -> list[str]` : `/I0/I3` → `["xi0", "xi3"]`
  - 각 단계에서 현재 서브서킷 소자 중 `prefix + name` (`inst_prefixes`, 대소문자 무시) 일치 검색
  - 반복 인스턴스 `I0<2>` → `iter_inst_patterns` 시도
  - 다음 단계 서브서킷 = 찾은 `x` 소자의 참조 서브서킷
- `voltage(sch_path, net) -> str` : `v(xi0.xi3.net12)`, top이면 `v(net12)`
  - 넷 존재 확인 (버스 → `bus_net_patterns`)
  - `ground_names` → 에러 "ground 프로브 불가"
  - 전역 넷(`!` 끝) → 그대로 `v(vdd!)`
- `current(sch_path, inst, term) -> str`
  - 소자 찾기 → 타입별:
    - `m/q/d/r/c` → `i{n}(<path>.<elem>)`, n = `current_terms[type][TERM.upper()]`, term 없으면 MOS는 `default_mos_term`
    - `x` → `isub(<path>.<elem>.<port>)` (port = term)  [VERIFY 문법]
    - `v/i` → `i(<path>.<elem>)`
- 실패 시 `NameMapError(후보 목록 포함)` → Probe.status = "error"
- 테스트: 합성 넷리스트 fixture로 top/2단 계층/반복/버스/전역넷/그라운드 케이스

### 6.6 deck.py — PrimeSim 덱

### 6.7 runner.py — 실행·감시

- 실행 디렉터리: `runs/<cell>_<YYYYMMDD_HHMMSS>/`

```
si/            si.env, si.log, 원본 넷리스트
netlist.sp     정리된 넷리스트
top.sp         덱
project.yaml   실행 시점 프로젝트 스냅샷
run_info.yaml  RunInfo
sim.out        primesim_sub stdout/stderr
<결과 파일>
```

- `class Runner`
  - `start(deck: Path) -> RunInfo` : `Popen(cmd, cwd=run_dir, stdout=sim.out, stderr=STDOUT)`
  - `poll() -> RunInfo` : 상태 갱신 (non-blocking, GUI 타이머/스레드에서 호출)
  - `wait(timeout) -> RunInfo`
  - `kill()` : sync → 프로세스 종료 / async → `kill_cmd`
  - `tail(n) -> list[str]` : 로그 끝부분
- 모드 판정
  - `sync`: 프로세스 종료 = 시뮬 종료, 종료코드 + `error_regex`로 성공 판정
  - `async`: `sim.out`에서 `job_id_regex` 추출 → `log_globs` 파일에서 `done_regex`/`error_regex` 폴링
  - `auto`: 프로세스가 30초 내 종료 + `job_id_regex` 매치 → async, 아니면 sync
- 완료 후 `output_globs`로 결과 파일 수집 → `RunInfo.outputs`
- 테스트: 가짜 실행 스크립트(`tests/bin/fake_primesim_sub` — sync/async 두 버전, 로그·결과 파일 생성)로 전 모드 검증

### 6.8 probe.py — 클릭 프로빙

**큐 레코드 (SKILL → Python)**

```
(kind topLib topCell topView path objType net inst term termNet)
 "V"  "myLib" "tb_inv" "schematic" "/I0" "line" "net12" "" "" ""
 "I"  "myLib" "tb_inv" "schematic" "/I0" "inst" ""     "M0" "D" "out"
```

**해석** `resolve(record, project, mapper, cfg) -> Probe`
- top 셀뷰 ≠ 프로젝트 테스트벤치 → error "다른 셀뷰에서 선택됨"
- kind V
  - `net` 있으면 → `mapper.voltage(path, net)`
  - `net` 없고 `termNet` 있으면 → `mapper.voltage(path, termNet)`
  - 인스턴스만 선택 → status "unresolved", GUI에서 터미널 선택 요청
- kind I
  - `inst` + `term` → `mapper.current(...)`
  - `inst`만 → MOS면 기본 D, 그 외 GUI 터미널 선택 요청
  - 와이어 선택 → error "전류는 소자 핀을 선택"
- 넷리스트가 아직 없으면 → status "unresolved", 넷리스트 생성 후 `re_resolve_all()` 자동 실행
- 중복(같은 expr) 무시

**폴러** `class ProbePoller`
- `poll_once() -> list[Probe]` : `bridge.call("vpsPopQueue")` → resolve → 새 프로브 반환
- GUI: QTimer(`poll_ms`), CLI: `vps probes --watch` 루프
- 브리지 오류 시 예외 대신 상태 플래그 (GUI 연결 표시등)

### 7.1 `skill/vps_core.il`

```lisp
procedure( vpsVersion() "vps-1")

procedure( vpsListLibs() ddGetLibList()~>name)

procedure( vpsListCells(lib view)
  let( (libObj out)
    libObj = ddGetObj(lib)
    when( libObj
      foreach( c libObj~>cells
        when( ddGetObj(lib c~>name view) out = cons(c~>name out))))
    sort(out 'alphalessp)))

;; 인스턴스 레코드: (instName lib cell ((param value cdfType parseAsCEL parseAsNumber) ...))
procedure( vpsInstRecords(cv)
  let( (recs params cdf cp)
    foreach( inst cv~>instances
      params = nil
      cdf = cdfGetInstCDF(inst)
      foreach( p inst~>prop
        when( stringp(p~>value)
          cp = and(cdf cdfFindParamByName(cdf p~>name))
          params = cons(list(p~>name p~>value
                             or(and(cp cp~>paramType) "")
                             or(and(cp cp~>parseAsCEL) "")
                             or(and(cp cp~>parseAsNumber) ""))
                        params)))
      recs = cons(list(inst~>name inst~>libName inst~>cellName reverse(params)) recs))
    reverse(recs)))

;; 하강할 view 선택: viewList 중 처음 존재하는 view, stopList/symbol이면 nil(leaf)
procedure( vpsPickView(lib cell viewList stopList)
  let( (found)
    foreach( v viewList
      when( and(!found ddGetObj(lib cell v)) found = v))
    if( and(found !member(found stopList) found != "symbol") then found else nil)))

procedure( vpsWalk(lib cell view path viewList stopList depth maxDepth)
  let( (cv subView out)
    cv = dbOpenCellViewByType(lib cell view nil "r")
    when( cv
      out = list(list(path lib cell view vpsInstRecords(cv)))
      when( depth < maxDepth
        foreach( inst cv~>instances
          subView = vpsPickView(inst~>libName inst~>cellName viewList stopList)
          when( subView
            out = append(out vpsWalk(inst~>libName inst~>cellName subView
                                     strcat(path "/" inst~>name)
                                     viewList stopList depth+1 maxDepth))))))
    out))

procedure( vpsGetHierarchy(lib cell view viewList stopList maxDepth)
  vpsWalk(lib cell view "" viewList stopList 0 maxDepth))

procedure( vpsOpenTestbench(lib cell view)
  geOpen(?lib lib ?cell cell ?view view ?mode "r")
  t)
```

### 7.2 `skill/vps_probe.il`

```lisp
vpsProbeQueue = nil
vpsProbeKind  = "V"
vpsProbeOn    = nil
vpsHiSets     = nil

;; 창의 하위 계층 경로 "/I0/I3" ("" = top)   [VERIFY 반환 순서, 반복 인스턴스 index]
procedure( vpsWinPath(win)
  let( (path)
    path = ""
    foreach( mi reverse(geGetHierMemInst(win))
      path = strcat(path "/" car(mi)~>name))
    path))

;; 클릭 좌표에 가장 가까운 인스턴스 터미널 → (termName netName)
procedure( vpsNearestTerm(inst pt)
  let( (best bestNet bestD d c)
    foreach( it inst~>instTerms
      foreach( pin it~>term~>pins
        c = centerBox(dbTransformBBox(pin~>fig~>bBox inst~>transform))
        d = (xCoord(c)-xCoord(pt))**2 + (yCoord(c)-yCoord(pt))**2
        when( or(!bestD d < bestD)
          bestD = d  best = it~>name  bestNet = and(it~>net it~>net~>name))))
    list(or(best "") or(bestNet ""))))

;; 큐 레코드: (kind topLib topCell topView path objType net inst term termNet)
procedure( vpsRecordFor(kind win obj pt)
  let( (top type net inst term termNet nt)
    top = geGetTopLevelCellView(win)
    type = obj~>objType
    net = ""  inst = ""  term = ""  termNet = ""
    cond(
      ( and(type == "inst" obj~>purpose == "pin")          ; 스케매틱 핀  [VERIFY]
        net = or(and(obj~>pin obj~>pin~>term~>name) "") )
      ( type == "inst"
        inst = obj~>name
        when( pt  nt = vpsNearestTerm(obj pt)  term = car(nt)  termNet = cadr(nt)) )
      ( obj~>net  net = obj~>net~>name ))                  ; wire / label
    list(kind top~>libName top~>cellName top~>viewName
         vpsWinPath(win) type net inst term termNet)))

procedure( vpsHilightObj(win obj)
  errset(
    let( (hs)
      hs = geCreateHilightSet(win list("y4" "drawing"))
      if( obj~>net
        then foreach( f obj~>net~>figs geAddHilightFig(hs f))
        else geAddHilightFig(hs obj))
      hs~>enable = t
      vpsHiSets = cons(hs vpsHiSets))))

procedure( vpsClearHilight()
  foreach( hs vpsHiSets errset(hs~>enable = nil))
  vpsHiSets = nil
  t)

;; 방식 A: 선택 후 단축키
procedure( vpsProbeSelected(kind)
  let( (win)
    win = hiGetCurrentWindow()
    foreach( obj geGetSelSet(win)
      vpsProbeQueue = cons(vpsRecordFor(kind win obj nil) vpsProbeQueue)
      vpsHilightObj(win obj))
    printf("VPS: %d probe(s) queued\n" length(vpsProbeQueue))))

;; 방식 B: 프로브 모드 (Python 버튼 → 클릭할 때마다 등록, Esc 종료)  [VERIFY 재무장 동작]
procedure( vpsStartProbeMode(kind)
  vpsProbeKind = kind
  vpsProbeOn = t
  enterPoint(?prompts list(sprintf(nil "VPS %s probe: click net/pin (Esc to stop)" kind))
             ?doneProc "vpsPointDone"
             ?alwaysMap t)
  t)

procedure( vpsStopProbeMode()
  vpsProbeOn = nil
  errset(cancelEnterFun())
  t)

procedure( vpsPointDone(win done pts)
  if( and(done pts vpsProbeOn)
    then
      let( (pt)
        pt = car(pts)
        geDeselectAll(win)
        geSingleSelectPoint(win t pt)                       ; [VERIFY 시그니처]
        foreach( obj geGetSelSet(win)
          vpsProbeQueue = cons(vpsRecordFor(vpsProbeKind win obj pt) vpsProbeQueue)
          vpsHilightObj(win obj))
        geDeselectAll(win)
        vpsStartProbeMode(vpsProbeKind))
    else vpsProbeOn = nil))

;; Python이 폴링 (SKILL 단일 스레드 → 원자적)
procedure( vpsPopQueue()
  let( (q) q = reverse(vpsProbeQueue)  vpsProbeQueue = nil  q))

;; 특정 넷 하이라이트 (GUI 표 선택 시) — 해당 계층 창이 열려 있으면 그 창에, 없으면 top 창에서 넷 이름 검색
procedure( vpsHilightProbe(lib cell path net) ...)   ; 에이전트 구현, best-effort, 실패 시 nil
```

- 실패해도 다음 항목 계속, 결과 표에 PASS/FAIL/SKIP
