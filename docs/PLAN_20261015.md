## 0. 에이전트 작업 규칙

- **GUI 애플리케이션** (CLI는 디버깅용 최소 진입점만)
- Python **3.11**, 타입힌트, `dataclasses`
- 개발 환경에 **Virtuoso·PrimeSim 없음**
  - Virtuoso 호출은 `Bridge` 인터페이스 뒤 → 테스트는 `FakeBridge`
  - si / primesim_sub 은 가짜 실행 스크립트(`tests/bin/`)로 테스트
  - 실연동 테스트는 `@pytest.mark.virtuoso` / `@pytest.mark.primesim` → 기본 skip
- 코어(`vps/core/`)는 Qt 없이 import 가능, GUI(`vps/gui/`)만 Qt 의존
- 의존성: `skillbridge`, `numpy`, `pyyaml`, `jinja2`, `qtpy`, `pyqtgraph`, `PyQt5` 또는 `PySide6`
- 품질: `pytest` 통과, `ruff check` 통과, GUI는 `QT_QPA_PLATFORM=offscreen` 스모크 테스트
- 커밋: 티켓 단위(§10), 브랜치 `claude/virtuoso-schematic-primesim-7sipmk`
- 생성 산출물(실행·히스토리 폴더 등) 이름에 날짜 `YYYYMMDD` 포함

## 1. 범위

### 포함 기능 (이것만 구현)
| # | 기능 | 요약 |
|---|---|---|
| F1 | 프로젝트 | 생성/열기/저장, 프로젝트 폴더 단위 관리 |
| F2 | 넷리스트 불러오기 | Virtuoso 테스트벤치 → si(hspiceD) 생성 **또는** 기존 넷리스트 파일 열기 → 변수 자동 추출 |
| F3 | 프로빙 | Virtuoso 스케매틱 클릭 → 전압/전류 프로브 등록 (+ GUI 넷 트리에서 선택 대안) |
| F4 | 웨이브폼 | 결과 파형 표시, 코너·스윕 겹쳐 그리기, 커서 |
| F5 | 계산 | 파형 수식 계산기 + 측정식(스칼라) → 결과 표·스윕 그래프 |
| F6 | 코너·파라메트릭 스윕 | 코너(모델 섹션·온도·변수) × 스윕(변수 값) 매트릭스 실행 |
| F7 | 히스토리 | 실행마다 설정·결과 스냅샷 저장, 다시 보기·비교·설정 복원 |

### 제외
- ADE 연동, 몬테카를로, 최적화, FSDB 직접 파싱, 보고서 생성

### 핵심 결정
- **변수는 넷리스트에서 추출** (스케매틱 순회 불필요 → SKILL 의존 최소화)
- **스윕/코너는 포인트마다 별도 덱·별도 잡** → 병렬 제출, 결과 파싱 단순, 실패 격리

- skillbridge 호출은 GUI 메인 스레드(QTimer)에서만, 시뮬 실행·파싱은 워커 스레드

├ 툴바: [넷리스트 갱신] [▶ Run] [■ Stop]   Virtuoso: ● 연결됨   프로젝트: amp_tb ───────────┤
├──────────────┬────────────────────────────────────────────────────────────────────────┤

│ │ 실행 목록 │ │                                                                        │
│ └─────────┘ │                                                                        │
├──────────────┴────────────────────────────────────────────────────────────────────────┤
│ 하단 Dock: 로그 (si / primesim / 앱 메시지, 에러 빨간색)                                   │

### 4.2 F1 프로젝트
- **새 프로젝트 다이얼로그**: 이름, 폴더 위치, 넷리스트 소스 선택
  - (a) Virtuoso 테스트벤치: lib / cell / view 입력 또는 [현재 Virtuoso 창에서 가져오기]
  - (b) 넷리스트 파일: 파일 선택
- 프로젝트 폴더

```
<project>/
  project.yaml          설정 전체 (§6)
  netlist/              si 작업 폴더, netlist.sp (정리본)
  history/              실행 스냅샷 (§7.8)
```

- 최근 프로젝트 목록 `~/.vps/recent.yaml`, 저장 안 된 변경 시 종료 확인

### 4.3 Setup 탭 (F2·F6)
세로 섹션 4개

1. **Netlist**: 소스 표시, [넷리스트 갱신], 마지막 생성 시각, 경고 수
2. **Variables** 표: 이름 / 기본값 / 사용처 수(툴팁에 위치) / 상태
   - 미입력 빨간색, 넷리스트 갱신 시 새 변수 추가·사라진 변수 회색(stale)
3. **Models & Analysis**
   - 모델: 파일 + 섹션 목록 (기본 코너용), include 파일, temp, `.option` 표
   - 분석: tran / dc / ac / op 목록 편집 (§7.4 인자)
4. **Corners & Sweep**
   - 코너 표: 사용(체크) / 이름 / 모델 섹션(파일별) / temp / 변수 덮어쓰기(`vdd=1.62, ...`)
     - 코너 0개 체크 → nominal 1개
   - 스윕 표: 변수 / 방식(list·lin·log) / 값(`1 2 3` 또는 start·stop·step/points)
     - 여러 변수 → 전체 조합
   - 하단: "총 N 포인트 = 코너 a × 스윕 b" 표시, N > 200 경고

### 4.4 Probes 탭 (F3)
- 버튼: [전압 프로브 모드] [전류 프로브 모드] [모드 종료] [하이라이트 지우기]
- 표: 종류 / 스케매틱 경로 / 넷·핀 / 넷리스트 식(`v(xi0.net12)`) / 별칭 / 상태
  - 별칭 편집 가능 → 계산기에서 이름으로 사용
  - 상태 error/unresolved 행: 더블클릭 → 터미널 선택 or 직접 입력
  - 행 선택 → Virtuoso 하이라이트
- 우측 접이식 **넷리스트 트리** (Virtuoso 없이도 프로빙): 서브서킷 계층 → 넷/소자 → 더블클릭으로 추가
- 옵션: [모든 노드 저장] 체크 → 프로브 대신 `.option probe=0` (용량 경고)

### 4.5 Waveform 탭 (F4·F5)
```
┌ 신호 트리 ─────────────┐┌ 플롯 영역 (pyqtgraph) ─────────────────────────┐
│ ▸ 실행(히스토리 항목)    ││ 스트립 1: vout (코너·스윕 포인트별 색)          │
│   ▸ 포인트 (corner/sweep)││ 스트립 2: i(m0)                               │
│     ☑ vout              ││  커서 A/B, Δx, Δy                             │
│     ☐ i(m0)             │└──────────────────────────────────────────────┘
│ 계산 결과(파형)          │┌ 계산기 ─────────────────────────────────────┐
│     ☑ deriv(vout)       ││ 식: [ deriv(vout)/1e9            ] [계산] [측정으로 저장] │
└─────────────────────────┘│ 함수 목록 버튼, 결과: 파형→플롯 / 스칼라→값 표시     │
                           └──────────────────────────────────────────────┘
```
- 신호 체크 → 선택 포인트 전부 겹쳐 그림, 범례 `corner/sweep값`
- 스트립 추가/삭제, 신호 드래그로 스트립 이동
- x축 로그(AC 자동), y: AC는 dB/위상 선택
- 우클릭: 이미지 저장, CSV 내보내기
- 다른 히스토리 실행 신호도 같은 플롯에 겹치기 가능 (비교)

### 4.6 Results 탭 (F5·F6)
- **측정식 목록** (프로젝트에 저장): 이름 / 식 / 사용 → 실행 끝나면 모든 포인트 자동 계산
- 결과 표: 행 = 포인트(corner, 스윕 변수들), 열 = 측정값, 상태
- [그래프]: 측정값 vs 스윕 변수 (코너별 선)
- [CSV 내보내기]

### 4.7 히스토리 Dock (F7)
- 목록: 날짜시간 / 이름 / 포인트 수 / 상태(✓ 성공 수 / ✗ 실패 수) / ★ / 메모
- 동작
  - 클릭 → Waveform·Results 탭에 해당 실행 로드
  - Ctrl+클릭 다중 선택 → 비교(겹쳐 그리기, 측정 표 병합)
  - 우클릭: 설정 복원(현재 Setup에 덮어쓰기), 이름·메모 수정, ★ 고정, 폴더 열기, 삭제
- 실행 시작 시 이름 기본값 `run_<YYYYMMDD_HHMMSS>`, 메모 입력 가능

## 6. 데이터 모델 (`core/models.py`) & project.yaml

```python
@dataclass(frozen=True)
class CellRef: lib: str; cell: str; view: str = "schematic"

@dataclass
class NetlistSource:
    kind: Literal["virtuoso", "file"]
    cell: CellRef | None = None
    file: str | None = None

@dataclass
class VarUse: subckt: str; element: str; param: str; expr: str

@dataclass
class Variable:
    name: str; value: str | None = None
    uses: list[VarUse] = field(default_factory=list); stale: bool = False

@dataclass
class ModelLib: path: str; section: str | None = None   # section 없으면 .include

@dataclass
class Analysis:
    kind: Literal["tran", "dc", "ac", "op"]; args: dict[str, str]

@dataclass
class Corner:
    name: str; enabled: bool = True
    sections: dict[str, str] = field(default_factory=dict)   # 모델 파일 경로 → 섹션
    temp: float | None = None
    vars: dict[str, str] = field(default_factory=dict)

@dataclass
class SweepVar:
    name: str; mode: Literal["list", "lin", "log"]
    values: list[str] = field(default_factory=list)       # list
    start: str = ""; stop: str = ""; step: str = ""; points: int = 0   # lin(step) / log(points per decade)

@dataclass
class Probe:
    kind: Literal["V", "I"]; sch_path: str = ""; net: str = ""; inst: str = ""; term: str = ""
    expr: str = ""; alias: str = ""
    status: Literal["ok", "unresolved", "error"] = "unresolved"; message: str = ""

@dataclass
class Measure: name: str; expr: str; enabled: bool = True

@dataclass
class Project:
    name: str; root: Path
    source: NetlistSource
    variables: dict[str, Variable]
    models: list[ModelLib]; includes: list[str]; temp: float | None
    options: dict[str, str]; analyses: list[Analysis]
    corners: list[Corner]; sweeps: list[SweepVar]
    probes: list[Probe]; measures: list[Measure]
    save_all_nodes: bool = False

@dataclass
class RunPoint:
    index: int; corner: str; sweep: dict[str, str]
    params: dict[str, str]         # 최종 적용 변수값
    dir: Path; status: Literal["pending", "running", "done", "failed", "killed"] = "pending"
    job_id: str | None = None; message: str = ""

@dataclass
class RunBatch:
    id: str                        # run_YYYYMMDD_HHMMSS
    name: str; note: str; starred: bool
    started: datetime; finished: datetime | None
    points: list[RunPoint]
```

- `project.yaml` = `Project` 직렬화 (경로는 프로젝트 기준 상대경로 저장)
- 스키마 버전 필드 `schema: 1` 포함

  comment_out: [".end", ".option", ".options", ".temp", ".tran", ".ac", ".dc", ".op", ".probe", ".print", ".alter"]
naming:                                            # [VERIFY]
  inst_prefixes: ["x", "m", "r", "c", "l", "d", "q", "v", "i", "e", "f", "g", "h", ""]
  iter_inst_patterns: ["{base}<{i}>", "{base}_{i}_", "{base}[{i}]"]

current_terms:
  m: {D: 1, G: 2, S: 3, B: 4}
  q: {C: 1, B: 2, E: 3, S: 4}
  d: {PLUS: 1, MINUS: 2, P: 1, N: 2, A: 1, K: 2}

### 7.2 netlister.py + netlistdb.py — F2

**넷리스트 생성 (소스 = virtuoso)**
1. `<project>/netlist/si/` 에 `si.env` 작성

   ```
   simLibName = "<lib>"
   simCellName = "<cell>"
   simViewName = "<view>"
   simSimulator = "hspiceD"
   simNotIncremental = 't
   simReNetlistAll = 't
   simViewList = '(<view_list>)
   simStopList = '(<stop_list>)
   simNetlistHier = 't
   ```
2. `si_cmd` 실행 (cwd=`work_dir`) → `si.log`
3. `output_candidates`로 결과 탐색 → 원본 복사
4. 정리본 `netlist/netlist.sp`: `comment_out` 지시문 줄(+연속줄)을 `* [vps] ` 접두로 주석
- 실패 → `NetlistError` + `si.log` 끝 50줄, `*ERROR*` 줄 → 로그 Dock

**넷리스트 파일 (소스 = file)**
- 원본은 그대로 두고 정리본만 `netlist/netlist.sp`로 생성

**파서** `parse_hspice(path) -> NetlistDB`
- `+` 연속줄 결합, `*` 주석줄·`$` 인라인 주석 제거, 대소문자 비구분 인덱스
- `.param a=1 b='a*2'` → 전역 파라미터
- `.subckt NAME ports... [p=v ...]` ~ `.ends` → `Subckt(name, ports, params, elements, nets)`
- 소자: 첫 글자로 타입
  - `x`: 노드 + 서브서킷명(첫 `=` 토큰 직전) + 파라미터
  - `m`: d g s b model params / 기타 타입별 노드 수 테이블
- 서브서킷 밖 → top
- `.include`/`.lib`은 따라가지 않음

**변수 추출** `find_design_vars(db) -> dict[str, Variable]`
- 모든 소자 파라미터 값 → `expr.identifiers()`
  - 따옴표(`'...'`) 내부도 수식으로 분석 (HSPICE 수식 표기)
  - 숫자+단위(`1u`, `10meg`, `1e-9`) 제외, `known_functions`·`reserved` 제외
- 정의된 이름 제외: 전역 `.param` ∪ 해당 서브서킷 `.subckt` 파라미터
- 남는 식별자 = 설계 변수, `VarUse` 기록
- MOS 모델명 등 비수식 토큰: `m` 소자의 model 위치 토큰은 파라미터가 아니므로 자연히 제외
- 기존 프로젝트 변수와 병합: 값 유지, 신규 추가, 없어진 것 `stale=True`

**NameMapper** (프로빙용)
- `map_path("/I0/I3") -> ["xi0", "xi3"]`
  - 각 단계: 현재 서브서킷 소자 중 `prefix + name`(대소문자 무시) 일치 → 반복 인스턴스는 `iter_inst_patterns`
- `voltage(path, net)` → `v(xi0.xi3.net12)` / top은 `v(net12)` / 전역넷 그대로 / ground → 에러
- `current(path, inst, term)`
  - `m q d r c` → `i{n}(<path>.<elem>)` (n = `current_terms`), MOS term 없으면 `default_mos_term`
  - `x` → `subckt_fmt`
  - `v i` → `i(<path>.<elem>)`
- 존재 검증 실패 → `NameMapError(후보)`

**테스트**: 합성 hspiceD 스타일 넷리스트 fixture (top + 2단 계층, 반복 인스턴스, 버스, 전역넷, `.param`, subckt 파라미터)

> 6.1.8 기준. [VERIFY] 는 field_check로 확인.

```lisp
vpsProbeQueue = nil
vpsProbeKind  = "V"
vpsProbeOn    = nil
vpsHiSets     = nil

procedure( vpsVersion() "vps-1")

;; 현재 창의 top 셀뷰 (프로젝트 생성 시 [현재 창에서 가져오기])
procedure( vpsCurrentTop()
  let( (top)
    top = geGetTopLevelCellView(hiGetCurrentWindow())
    when( top list(top~>libName top~>cellName top~>viewName))))

procedure( vpsOpenTestbench(lib cell view)
  geOpen(?lib lib ?cell cell ?view view ?mode "r") t)

;; 창의 하위 계층 경로 "/I0/I3" ("" = top)   [VERIFY 반환 순서]
procedure( vpsWinPath(win)
  let( (path)
    path = ""
    foreach( mi reverse(geGetHierMemInst(win))
      path = strcat(path "/" car(mi)~>name))
    path))

;; 클릭 좌표에 가장 가까운 인스턴스 터미널 → (termName netName)
procedure( vpsNearestTerm(inst pt)
  let( (best bestNet bestD d c)
    foreach( it inst~>instTerms
      foreach( pin it~>term~>pins
        c = centerBox(dbTransformBBox(pin~>fig~>bBox inst~>transform))
        d = (xCoord(c)-xCoord(pt))**2 + (yCoord(c)-yCoord(pt))**2
        when( or(!bestD d < bestD)
          bestD = d  best = it~>name  bestNet = and(it~>net it~>net~>name))))
    list(or(best "") or(bestNet ""))))

;; 큐 레코드: (kind topLib topCell topView path objType net inst term termNet)
procedure( vpsRecordFor(kind win obj pt)
  let( (top type net inst term termNet nt)
    top = geGetTopLevelCellView(win)
    type = obj~>objType
    net = ""  inst = ""  term = ""  termNet = ""
    cond(
      ( and(type == "inst" obj~>purpose == "pin")                 ; 스케매틱 핀 [VERIFY]
        net = or(and(obj~>pin obj~>pin~>term~>name) "") )
      ( type == "inst"
        inst = obj~>name
        when( pt  nt = vpsNearestTerm(obj pt)  term = car(nt)  termNet = cadr(nt)) )
      ( obj~>net  net = obj~>net~>name ))                         ; wire / label
    list(kind top~>libName top~>cellName top~>viewName
         vpsWinPath(win) type net inst term termNet)))

procedure( vpsHilightObj(win obj)
  errset(
    let( (hs)
      hs = geCreateHilightSet(win list("y4" "drawing"))
      if( obj~>net
        then foreach( f obj~>net~>figs geAddHilightFig(hs f))
        else geAddHilightFig(hs obj))
      hs~>enable = t
      vpsHiSets = cons(hs vpsHiSets))))

procedure( vpsClearHilight()
  foreach( hs vpsHiSets errset(hs~>enable = nil))
  vpsHiSets = nil  t)

;; 방식 A: 선택 후 단축키
procedure( vpsProbeSelected(kind)
  let( (win)
    win = hiGetCurrentWindow()
    foreach( obj geGetSelSet(win)
      vpsProbeQueue = cons(vpsRecordFor(kind win obj nil) vpsProbeQueue)
      vpsHilightObj(win obj))
    printf("VPS: %d probe(s) queued\n" length(vpsProbeQueue))))

;; 방식 B: 프로브 모드 (GUI 버튼 → 클릭마다 등록, Esc 종료)   [VERIFY 재무장]
procedure( vpsStartProbeMode(kind)
  vpsProbeKind = kind  vpsProbeOn = t
  enterPoint(?prompts list(sprintf(nil "VPS %s probe: click net/pin (Esc to stop)" kind))
             ?doneProc "vpsPointDone" ?alwaysMap t)
  t)

procedure( vpsStopProbeMode()
  vpsProbeOn = nil  errset(cancelEnterFun())  t)

procedure( vpsPointDone(win done pts)
  if( and(done pts vpsProbeOn)
    then
      let( (pt)
        pt = car(pts)
        geDeselectAll(win)
        geSingleSelectPoint(win t pt)                                ; [VERIFY 시그니처]
        foreach( obj geGetSelSet(win)
          vpsProbeQueue = cons(vpsRecordFor(vpsProbeKind win obj pt) vpsProbeQueue)
          vpsHilightObj(win obj))
        geDeselectAll(win)
        vpsStartProbeMode(vpsProbeKind))
    else vpsProbeOn = nil))

;; Python 폴링 (SKILL 단일 스레드 → 원자적)
procedure( vpsPopQueue()
  let( (q) q = reverse(vpsProbeQueue)  vpsProbeQueue = nil  q))

;; GUI 표 선택 시 하이라이트: path 계층 창이 열려 있으면 그 창, 아니면 top 창에서 넷 검색
procedure( vpsHilightProbe(lib cell path net) ...)   ; 에이전트 구현, best-effort, 실패 시 nil
```
