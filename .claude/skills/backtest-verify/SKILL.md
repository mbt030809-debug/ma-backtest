# 백테스트 검증

## 실행
- 전체: `bash backtest/tests/run_all_20261106.sh` (약 1분). 엔진 검사 → 모의 서버(`MOCK=1`, 포트 8190) 기동 → Playwright 화면 검사 → 서버 종료.
- 엔진만: `node backtest/tests/engine_checks_20261106.js` (네트워크 불필요, 수 초).

## 무엇을 확인하나
- **엔진:** 세금 규칙(매도 없으면 0, 연도 통산 후 다음 해 5/1 납부, 현금 이자 제외), 손익 항등식(최종−100 = TECL손익+방어손익+이자−납부세금), 지연 중 상태 우선(최종 상태=마지막 신호), 장기선 우세, 이평별 지연, 방어 ETF 상장 전 = 현금.
- **화면:** 일반 실행 = 스윕 = 방어 ETF 스캔(같은 설정이면 소수점까지 동일), 상장 늦은 방어 ETF, 앱 재시작 후 결과 복원, 이평 워밍업 시작일.

## 주의 (겪은 함정)
- 화면은 탭 4개(백테스트 / 최적값 찾기 / 방어 ETF / 알림·설정). 다른 탭의 입력은 숨겨져 있어 Playwright `fill` 이 안 되므로 `showTab('sw')` 로 탭을 바꾸거나 테스트처럼 `.tab{display:block!important}` 스타일을 넣는다.
- 엔진을 바꾸면 **세 경로(run / 스윕 워커 / prepScan)** 를 모두 같은 규칙으로 맞춰야 한다. 스윕 워커 코드는 `index_20261030.html` 안의 템플릿 문자열(`WK`)이라 백틱 안에서 `${}` 를 쓰면 안 된다.
- Playwright `waitForFunction(fn, arg, options)` — 옵션은 **세 번째** 인자(`null, {polling:500, timeout}`). 기본 rAF 폴링은 무거운 스캔 중 렌더러를 죽일 수 있다.
- 숨김(`type=hidden`)·닫힌 `<details>` 안 입력은 `fill` 이 안 된다 → 먼저 `details` 를 열거나 `evaluate` 로 값을 넣는다.
- 모의 서버는 시작일에 따라 시세가 달라지는 모의 데이터다. 실제 시세(Yahoo)는 이 환경에서 막혀 있으므로 **실제 수익률·MDD 는 검증 불가** — 그렇게 보고한다.
- 개발 서버를 끌 때 `pkill -f server_20261030.py` 는 쓰지 않는다(셸까지 죽음). 시작할 때 PID 를 받아 `kill` 한다.
- 시세 캐시(IndexedDB)는 정리 시 커서로 전체를 훑지 않는다(`__meta` 목록 사용).
