# 설명용 차트 만들기

## 방법
1. 짧은 가상 가격(20일 안팎)과 신호 위치를 직접 정해 **실제 엔진**(`backtest/engine_20261030.js`)으로 돌린다 — 그림이 실제 동작과 어긋나지 않게 한다.
2. Node 에서 SVG 문자열을 만들고 Playwright(`chromium`)의 `page.setContent` + `screenshot` 으로 PNG 저장. 한글 폰트는 기본 렌더링으로 충분히 표시된다(확인함).
3. 구성 예: 위 패널 = 가격·이평선·신호(▲ 매수신호/▼ 매도신호), 아래 패널들 = 방식별 보유(초록)/현금(빨강) 띠 + 체결 화살표 + 취소(✕).
4. 참고 구현: `example_draw_delay_20261106.js` (지연 3일/1일, 옛 방식 vs 상태 우선 비교).

## 규칙
- 파일은 스크래치패드(또는 사용자에게 열리는 작업 폴더)에 `이름_YYYYMMDD.png` 로 저장하고 `SendUserFile` 로 전달(`display: 'render'`).
- 그림은 "가상 가격(설명용)" 이라고 표시한다.
- 만든 뒤 `Read` 로 이미지를 열어 겹침·방향(▲/▼)이 맞는지 확인하고 고친다.
- 답변은 장면 → 결과 → 핵심 한 줄, 개조식으로 짧게.
